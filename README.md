## Collaborative Writing

This booklet is a **community-driven, open-source project**. We welcome contributions from anyone interested in improving keyboard ergonomics, typing techniques, or related topics.

- **New chapters** on keyboard-related subjects are welcome
- **Improvements** to existing content are encouraged
- **Translations** to other languages are appreciated
- All contributions must be licensed under **CC BY-SA 4.0** to maintain consistency

Robert Winkler serves as the editor, ensuring quality and coherence while maintaining a permissive and constructive approach to community contributions.

## mdBook: HTML, PDF, and epub creation
If you are lucky (i.e. the compilation on the GitHub repository worked), you can browse the current version of the booklet on: 
<https://robert-winkler.github.io/strain-free-typing-booklet/>

You can build the PDF and epub versions locally, using
~~~
mdbook build
~~~
within the cloned repository.

Of course, you need `mdbook`, and `mdbook-pandoc` installed, as well as their dependencies.

## Contributing
Community contributions are welcome!

To contribute:

1. **Fork** the repository on GitHub
2. **Clone** your fork locally
3. **Create a feature branch** for your changes
4. **Make your changes** (new chapters, improvements, corrections)
5. **Submit a pull request** with a clear description of your contribution

All contributions should:

- Be original work or properly attributed
- Follow the existing style and structure
- Be relevant to the book's focus on keyboards, ergonomics, and typing
- Be licensed under CC BY-SA 4.0

Contributors will be recognized in the [Authors and Contributors](src/authors.md) section of the book.
