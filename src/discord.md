# Discord Channels

Discord ([https://discord.com/](https://discord.com/)) is an online chatting platform. Several channels deal with building, programming, and using special keyboards:

- **QMK**: Building and programming keyboards.
- **Colemak**: Discussion and support for new Colemak users.
- **Plover**: Very nice and helpful group for Steno/Plover friends.
- **Splitkb.com**: Ideas for split keyboards; mainly focused on splitkb.com products, but open to other builds as well.
